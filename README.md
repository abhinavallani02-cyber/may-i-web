# may-i-web

The marketing/landing page for [may-i](https://github.com/abhinavallani02-cyber/mayI) — a permission
layer for AI agents. The homepage is a static page served by Vite.

This is the website only. For the actual proxy (the `mayi-mcp` npm package / `mayi` CLI), see the
[mayI repo](https://github.com/abhinavallani02-cyber/mayI).

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Outputs a static site to `dist/`.
